## What Tevet-7 Does

You connect your business database to Tevet-7 through a guided onboarding wizard. Once connected, your team can ask questions in plain language — the AI agent translates them into SQL, searches your document knowledge base, or runs ML forecasting models to produce an answer.

Every query is protected by three independent security layers: JWT-extracted identity (your credentials never travel in the request body), read-only database connections, and AST-level row-level scoping that injects the correct `WHERE` clause before any query reaches the database.

## Get Started in 3 Steps

<Steps>
  <Step title="Create your account">
    Sign up via `POST /api/auth/signup` and receive a JWT. [See the Authentication guide →](/guides/authentication)
  </Step>
  <Step title="Create a workspace and connect your data">
    Create a tenant, run the onboarding wizard to connect PostgreSQL or upload a CSV, and let Tevet-7 detect your schema automatically. [See the Onboarding guide →](/guides/onboarding)
  </Step>
  <Step title="Start asking questions">
    Send a `POST /api/chat` request with your question. Receive a structured answer with the SQL used, data visualisation spec, and cited sources. [See the Chat guide →](/guides/chat)
  </Step>
</Steps>

## Try the Live Demo

Tevet-7 ships with a pre-configured demo tenant (Drive Producteur) you can explore without creating an account.

```bash
curl -X POST https://your-tevet7-host/api/auth/demo-token
# Returns a JWT for the demo producer account
```

Use the returned token as `Authorization: Bearer <token>` on any `/api/chat` call to query the Drive Producteur dataset.
