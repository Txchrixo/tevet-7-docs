---
title: "GET /api/documents — List Knowledge Base Documents"
sidebarTitle: "List Documents"
description: "Retrieve all documents in your tenant's knowledge base, with optional producer scoping, and inspect individual document chunks for audit or debugging."
---

Use these endpoints to audit the contents of your tenant's knowledge base before running documentary queries. You can list every document the agent can access, optionally narrow the results to a specific producer's documents, and drill into a single document to view its raw content and every indexed chunk.

---

## List All Documents

```
GET /api/documents
```

**Authorization:** `Bearer <token>`

### Query Parameters

<ParamField query="producer_id" type="integer">
  When provided, the response includes tenant-wide documents (those with no producer assignment) **plus** documents belonging to the specified producer. Omit this parameter to return all documents across the tenant. When you authenticate with a producer-role token, the server automatically applies the correct producer scope from your JWT.
</ParamField>

### Response

<ResponseField name="count" type="integer">
  Total number of documents returned.
</ResponseField>

<ResponseField name="documents" type="array">
  An array of document summary objects. Each object contains the following fields:

  <ResponseField name="id" type="integer">
    Unique document ID.
  </ResponseField>

  <ResponseField name="title" type="string">
    The title assigned when the document was uploaded.
  </ResponseField>

  <ResponseField name="source_type" type="string">
    `"pdf"` or `"text"`.
  </ResponseField>

  <ResponseField name="source_filename" type="string | null">
    Original filename of the uploaded PDF. `null` for text-type documents.
  </ResponseField>

  <ResponseField name="producer_id" type="integer | null">
    The producer this document is scoped to, or `null` if it is a tenant-wide document.
  </ResponseField>

  <ResponseField name="created_at" type="string">
    ISO 8601 timestamp of when the document was ingested.
  </ResponseField>

  <ResponseField name="chunks_count" type="integer">
    Number of indexed text chunks derived from this document.
  </ResponseField>
</ResponseField>

### Example

```bash
# List all documents for your tenant
curl -X GET https://your-host/api/documents \
  -H "Authorization: Bearer <token>"

# Scope to a specific producer
curl -X GET "https://your-host/api/documents?producer_id=7" \
  -H "Authorization: Bearer <token>"
```

```json
{
  "count": 2,
  "documents": [
    {
      "id": 42,
      "title": "Terms of Service",
      "source_type": "pdf",
      "source_filename": "terms.pdf",
      "producer_id": null,
      "created_at": "2024-11-01T09:30:00",
      "chunks_count": 18
    },
    {
      "id": 43,
      "title": "FAQ",
      "source_type": "text",
      "source_filename": null,
      "producer_id": 7,
      "created_at": "2024-11-02T14:15:00",
      "chunks_count": 5
    }
  ]
}
```

## Get Document Detail

Retrieve the full content and every indexed chunk for a single document.

```
GET /api/documents/{id}
```

**Authorization:** `Bearer <token>`

### Path Parameters

<ParamField path="id" type="integer" required>
  The document ID returned by the upload or list endpoint.
</ParamField>

### Response

<ResponseField name="id" type="integer">
  Document ID.
</ResponseField>

<ResponseField name="tenant_id" type="string">
  The tenant this document belongs to.
</ResponseField>

<ResponseField name="title" type="string">
  Document title.
</ResponseField>

<ResponseField name="source_type" type="string">
  `"pdf"` or `"text"`.
</ResponseField>

<ResponseField name="source_filename" type="string | null">
  Original PDF filename, or `null` for text documents.
</ResponseField>

<ResponseField name="producer_id" type="integer | null">
  Scoped producer, or `null` for tenant-wide documents.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 ingestion timestamp.
</ResponseField>

<ResponseField name="content_raw" type="string">
  The full raw text that was indexed — the extracted PDF text or the `content` string you supplied on upload.
</ResponseField>

<ResponseField name="chunks" type="array">
  The ordered list of text chunks stored in the vector index. Each chunk contains:

  <ResponseField name="id" type="integer">
    Unique chunk ID.
  </ResponseField>

  <ResponseField name="chunk_index" type="integer">
    Zero-based position of this chunk within the document.
  </ResponseField>

  <ResponseField name="content" type="string">
    The text content of this chunk.
  </ResponseField>

  <ResponseField name="created_at" type="string">
    ISO 8601 timestamp for when this chunk was created.
  </ResponseField>
</ResponseField>

### Example

```bash
# Get full detail for document 42
curl -X GET https://your-host/api/documents/42 \
  -H "Authorization: Bearer <token>"
```

```json
{
  "id": 42,
  "tenant_id": "acme",
  "title": "Terms of Service",
  "source_type": "pdf",
  "source_filename": "terms.pdf",
  "producer_id": null,
  "created_at": "2024-11-01T09:30:00",
  "content_raw": "1. Definitions\nThe following terms apply...",
  "chunks": [
    {
      "id": 201,
      "chunk_index": 0,
      "content": "1. Definitions\nThe following terms apply...",
      "created_at": "2024-11-01T09:30:01"
    },
    {
      "id": 202,
      "chunk_index": 1,
      "content": "2. Obligations of the Producer...",
      "created_at": "2024-11-01T09:30:01"
    }
  ]
}
```
