---
title: "Export Conversations and Query Analytics from Tevet-7"
sidebarTitle: "Export"
description: "Download your tenant's conversation history and query analytics as CSV or PDF — ready for BI tools, compliance archives, or usage reports."
---

Tevet-7 lets you export your tenant's full conversation history and query analytics in two formats: CSV for data analysis and PDF for reports or compliance archives. All export endpoints require a valid Bearer token and return only the data belonging to your tenant.

<Note>
  Exports are scoped to your tenant. You will only ever see data from your own workspace — another tenant's conversations are never included, regardless of your role.
</Note>

---

## Export all conversations as CSV

```bash
GET /api/export/conversations.csv
```

Downloads a CSV file containing the 1,000 most recent conversations for your tenant, ordered by date descending.

**CSV columns**

| Column | Description |
|---|---|
| `id` | Unique trace/conversation ID |
| `created_at` | Timestamp of the query |
| `identity_id` | User who sent the query |
| `user_message` | The original user question |
| `intent` | Agent-classified intent (e.g. `top_products`, `weekly_sales`) |
| `sql_generated` | SQL statement generated by the agent |
| `tokens_in` | Input tokens consumed |
| `tokens_out` | Output tokens generated |
| `latency_ms` | End-to-end response time in milliseconds |
| `refused` | Whether the agent refused the query (`true`/`false`) |
| `cost_usd` | Estimated LLM cost for the query |

**Example**

```bash
curl -X GET "https://your-tevet7-instance.com/api/export/conversations.csv" \
  -H "Authorization: Bearer <your_token>" \
  -o conversations.csv
```

## Export all conversations as PDF

```bash
GET /api/export/conversations.pdf
```

Downloads a PDF report with a formatted table of your tenant's conversations. Useful for compliance reviews or stakeholder reports where a spreadsheet is not appropriate.

```bash
curl -X GET "https://your-tevet7-instance.com/api/export/conversations.pdf" \
  -H "Authorization: Bearer <your_token>" \
  -o conversations.pdf
```

The PDF table includes the same core fields as the CSV export: date, user, question, intent, total tokens, and whether the query was refused.

---

## Export a single conversation

```bash
GET /api/export/messages/{conversation_id}.csv
```

Downloads a CSV of all individual messages in one conversation — both the user turns and the assistant replies. Useful for auditing a specific session or debugging an unexpected agent response.

**CSV columns**

| Column | Description |
|---|---|
| `id` | Message ID |
| `role` | `user` or `assistant` |
| `content` | Full message text |
| `sql` | SQL generated (assistant messages only) |
| `tokens_in` | Input tokens for this message |
| `tokens_out` | Output tokens for this message |
| `created_at` | Timestamp |

**Example**

```bash
curl -X GET "https://your-tevet7-instance.com/api/export/messages/conv_xyz789.csv" \
  -H "Authorization: Bearer <your_token>" \
  -o conversation_xyz789.csv
```

---

<Tip>
  Import the CSV export directly into Excel, Tableau, or any BI tool to analyze your users' query patterns, track which intents are most common, measure average latency over time, or identify questions the agent refused more than expected.
</Tip>
