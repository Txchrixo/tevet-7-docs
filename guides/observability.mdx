Every time a user sends a message to the AI agent, Tevet-7 records a trace. That trace captures everything that happened: the SQL the agent generated, how many tokens were consumed, how long the response took, which tools were called, and whether the query was refused. You can browse these traces through the API or, when Langfuse is configured, through a full LLM observability dashboard.

<Tip>
  Every chat response includes a `trace_id` field. Pass it directly to `GET /api/traces/{trace_id}` to pull up the full execution detail for that specific query.
</Tip>

---

## List recent traces

```bash
GET /api/traces?limit=50
```

Returns the most recent traces for your tenant, newest first. The default limit is 50; you can request up to 200.

**Query parameters**

<ParamField query="limit" type="integer" default="50">
  Number of traces to return. Maximum: 200.
</ParamField>

**Example**

```bash
curl -X GET "https://your-tevet7-instance.com/api/traces?limit=20" \
  -H "Authorization: Bearer <your_token>"
```

**Each trace summary includes:**

<ResponseField name="id" type="string">
  Unique trace identifier. Use this to fetch the full detail.
</ResponseField>
<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the query was processed.
</ResponseField>
<ResponseField name="identity_id" type="string">
  The user or agent identity that sent the query (e.g. `marie@example.com`).
</ResponseField>
<ResponseField name="intent" type="string">
  The intent the agent classified the query as (e.g. `top_products`, `weekly_sales`, `stock_shortfall`).
</ResponseField>
<ResponseField name="tokens_in" type="integer">
  Number of input tokens consumed.
</ResponseField>
<ResponseField name="tokens_out" type="integer">
  Number of output tokens generated.
</ResponseField>
<ResponseField name="latency_ms" type="integer">
  End-to-end response latency in milliseconds.
</ResponseField>
<ResponseField name="refused" type="boolean">
  Whether the agent refused to answer this query (e.g. out-of-scope question, security block).
</ResponseField>
<ResponseField name="cost_usd" type="number">
  Estimated LLM cost for this query in US dollars.
</ResponseField>

**Example trace summary**

```json
{
  "id": "trace_abc123",
  "created_at": "2025-01-15T10:30:00",
  "identity_id": "marie@example.com",
  "intent": "top_products",
  "tokens_in": 450,
  "tokens_out": 120,
  "latency_ms": 1240,
  "refused": false,
  "cost_usd": 0.00042
}
```

## Get trace detail

```bash
GET /api/traces/{trace_id}
```

Returns the full trace record for a single query — including the SQL statement the agent generated, the reasoning steps, tool calls made, the answer excerpt, and the full token accounting.

```bash
curl -X GET "https://your-tevet7-instance.com/api/traces/trace_abc123" \
  -H "Authorization: Bearer <your_token>"
```

The detail response extends the summary with:

<ResponseField name="sql" type="string">
  The SQL statement generated by the agent (after sqlglot rewriting and scoping injection).
</ResponseField>
<ResponseField name="steps" type="array">
  Ordered list of reasoning steps the agent took, each with a title, detail, status, and duration.
</ResponseField>
<ResponseField name="tool_calls" type="array">
  List of tools invoked (e.g. `sql_read`, `rag_search`, `forecast`) with per-tool latency and success flag.
</ResponseField>
<ResponseField name="answer" type="string">
  Excerpt of the agent's natural-language answer.
</ResponseField>

## Langfuse integration

When both `LANGFUSE_PUBLIC_KEY` and `LANGFUSE_SECRET_KEY` are set in your environment, Tevet-7 sends traces to Langfuse Cloud in addition to storing them locally. This gives you a full LLM observability dashboard with:

- Timeline views across all your tenants' queries
- Token usage and cost aggregations by model and intent
- Session-level trace grouping for multi-turn conversations
- Alerting on latency spikes or unexpected refusal rates

```bash
# In your .env file
LANGFUSE_PUBLIC_KEY=pk-lf-your-key-here
LANGFUSE_SECRET_KEY=sk-lf-your-key-here
LANGFUSE_HOST=https://cloud.langfuse.com   # omit to use Langfuse Cloud default
```

When neither key is configured, Tevet-7 falls back to `LocalTracer`, which stores all traces in the local SQLite database. The `/api/traces` endpoints work identically in both modes.

## Cost accounting

Every trace includes a `cost_usd` field with the estimated LLM spend for that query. The calculation is based on the provider's published token pricing for the model used. You can use this field to:

- Track spend per user or per intent category
- Set internal usage budgets per tenant
- Identify expensive query patterns worth caching or simplifying

---

## Token quotas

Each tenant has a hard daily token quota — the default is **200,000 tokens per UTC day**. When a query would exceed your quota, the agent returns HTTP `429 Too Many Requests`. The quota resets at 00:00 UTC.

You can adjust the default quota by setting `TOKEN_QUOTA_PER_TENANT_PER_DAY` in your environment configuration.
